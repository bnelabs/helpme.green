Local app

Start helpme.green through its local server

Opening static/index.html directly cannot load the local assistant, saved settings, or server-backed notes.

From the repository root, run:

PYTHONPATH=src .venv/bin/python -m helpme_green --serve --host 127.0.0.1 --port 8080

Then open http://127.0.0.1:8080/. Keep HELPME_MASTER_KEY configured if you want to save an encrypted provider API key.
